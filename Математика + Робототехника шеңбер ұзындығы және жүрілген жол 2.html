Шеңбердің ұзындығы
Шеңбер ұзындығы және дөңгелектің жүрген жолы
Шеңбер туралы еске түсірейік
Бүгінгі тақырып: дөңгелектің айналымы және жүрілген жол
Сұрақ 1
Радиус деген не?
Сұрақ 2
Диаметр деген не? Ол радиуспен қалай байланысты?
Сұрақ 3
π саны деген не? Оның шамамен мәні қандай?
Сұрақ 4
Шеңбер ұзындығы деген не? Бүгін оны толығырақ білеміз
Шеңбер ұзындығын қалай табуға болады?
1. Дөңгелектің диаметрін d өлшейміз.
2. Дөңгелекті бір рет толық домалатамыз: ізінің ұзындығы C.
3. C мен d-ны салыстырамыз: C ≈ 3,14·d.
Бірінші формула: шеңбер ұзындығы
C = π·d = 2πr
d = 2r болғандықтан, C = π·d = 2πr.
C — шеңбер ұзындығы: дөңгелектің 1 айналымындағы жол
r — радиус, d — диаметр
π ≈ 3,14
Көп айналым болса, жол қалай өзгереді?

Әр айналымда бірдей C қашықтық қосылады.
Екінші формула: жүрілген жол
S = n · 2πr
S = n·C және C = 2πr болғандықтан. Керісінше: n = S / (2πr)
S — жүрілген жол
n — дөңгелектің айналым саны
r — дөңгелектің радиусы
Ойын: Финишке жет!

  • Дұрыс жауап — дөңгелек бір қадам алға домалайды.
  • Қате болса — орнында қалады, дұрыс жауап көрсетіледі.

Тапсырма: робот-құтқарушы
Роботтың алдында адам тұр. Робот адамға тиіп кетпей, оның алдында тоқтауы керек. Бағдарлама: дөңгелектің неше айналымына алға жүру керек?
1 · Анықта
Дөңгелектің диаметрін өздерің табыңдар.
2 · Есепте
Роботты қауіпсіз тоқтататын айналым санын есептеңдер.
3 · Тексер
Симуляторда тексеріңдер. Қате болса, себебін іздеңдер.
Рефлексия
Шеңбер ұзындығы мен жүрілген жол қалай байланысты?
Робот есебінде қандай қиындық кездесті?
Бұл формулаларды қайда қолдануға болады?
Өз сенімділігіңді 1-ден 5-ке дейін бағала.
Қорытынды
C = 2πr · S = n·2πr · n = S / (2πr)
  • Дөңгелектің 1 айналымы — шеңбер ұзындығына тең жол.
  • n айналымда жол n есе көп: S = n·2πr.
  • Нақты есепте роботтың барлық өлшемдері маңызды.
