Шеңбер ұзындығын қалай табуға болады?
1. Дөңгелектің диаметрін d өлшейміз.
2. Дөңгелекті бір рет толық домалатамыз: ізінің ұзындығы C.
3. C мен d-ны салыстырамыз: C ≈ 3,14·d.
Бірінші формула: шеңбер ұзындығы
C = π·d = 2πr
d = 2r болғандықтан, C = π·d = 2πr.
C — шеңбер ұзындығы: дөңгелектің 1 айналымындағы жол
r — радиус, d — диаметр
π ≈ 3,14

Екінші формула: жүрілген жол
S = n · 2πr
S = n·C және C = 2πr болғандықтан. Керісінше: n = S / (2πr)
S — жүрілген жол
n — дөңгелектің айналым саны
r — дөңгелектің радиусы

Тапсырма: робот-құтқарушы
Роботтың алдында адам тұр. Робот адамға тиіп кетпей, оның алдында тоқтауы керек. Бағдарлама: дөңгелектің неше айналымына алға жүру керек?
1 · Анықта
Дөңгелектің диаметрін өздерің табыңдар.
2 · Есепте
Роботты қауіпсіз тоқтататын айналым санын есептеңдер.
3 · Тексер
Симуляторда тексеріңдер. Қате болса, себебін іздеңдер.
